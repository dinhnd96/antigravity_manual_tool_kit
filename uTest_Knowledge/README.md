# 📖 uTest Knowledge Base

> Kho kiến thức dịch thuật EN → VI cho nền tảng uTest và QA/Testing.
> Được quản lý tự động bởi AI Translator Skill.

## 📁 Cấu trúc thư mục

```
uTest_Knowledge/
├── glossary.md          ← Bảng thuật ngữ EN↔VI (tích lũy tự động)
├── academy/             ← Nội dung dịch từ uTest Academy (courses)
├── test_cycles/         ← Hướng dẫn về test cycle, bug report
├── platform/            ← Hướng dẫn nền tảng (rating, payment, profile)
└── general/             ← Nội dung chung không thuộc category nào
```

## 🚀 Cách sử dụng

### Yêu cầu dịch mới
Gửi cho AI một trong các lệnh:
- `dịch và lưu: [paste nội dung tiếng Anh]`
- `dịch: [paste nội dung tiếng Anh]`
- `dịch URL: [link trang web]`

### Tra cứu thuật ngữ
- Mở file `glossary.md` để xem bảng thuật ngữ
- Tìm kiếm trong các thư mục theo chủ đề

### Xem lại bản dịch cũ
- Duyệt các file `.md` trong thư mục tương ứng
- Mỗi file có metadata: nguồn gốc, ngày dịch, chủ đề
